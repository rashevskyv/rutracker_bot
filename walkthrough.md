# Звіт про виконану роботу: Валідація збігу назв ігор у регіональному пошуку цін (v0.7.22)

## Огляд проблеми
Користувач надав скріншот з повідомленням бота про `Hogwarts Legacy`:
- Бот показав: Аргентина ~7 грн, Чилі ~70 грн, США $1.99 (~89 грн).
- Водночас у Польщі та Норвегії ціни були ~3000 грн, а на eShop-Prices гра коштує понад 2000 грн.

---

## Причина розбіжності та виправлення

1. **Що сталося**:
   - Американський API Nintendo (Algolia) не мав точного індексу для назви `Hogwarts Legacy` і за нечітким пошуком слова `Legacy` першим результатом повернув гру **`Unstrong Legacy`** (яка коштує $1.99 в США та 218 ARS в Аргентині).
   - Модуль `RegionPriceService` брав перший знайдений результат `hits[0]` без перевірки збігу самої назви. Через це для регіонів Америки підставилися ціни зовсім іншої гри.
2. **Виправлення**:
   - Впроваджено функцію суворої перевірки збігу слів/токенів назви `_is_title_match()`. Якщо назва знайденої гри в американському каталозі не збігається із запитуваною, результат відхиляється.
   - Очищено застарілий кеш цін.
   - Тепер для `Hogwarts Legacy` повертаються виключно реальні офіційні ціни (Польща 269 PLN, Норвегія 629 NOK, ПАР 1069 ZAR тощо).
3. **Тестування**:
   - Додано юніт-тест `test_title_similarity_guardrail`.
   - Усі 21 тест пройдено паралельно (`pytest -v -n auto`).
