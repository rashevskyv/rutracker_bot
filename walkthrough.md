# Звіт про виконану роботу: Точкове видалення гри з вітрини за назвою (v0.7.23)

## Огляд задачі
Користувач запитав, як видалити конкретно Hogwarts Legacy з чату та перезапустити публікацію гри з реальними цінами.

---

## Реалізовані можливості

1. **Видалення конкретної гри за назвою**:
   - Через Telegram-команду у топіку вітрини `561344`:
     ```text
     /remove Hogwarts Legacy
     ```
     (або `/видалити Hogwarts Legacy`)
   - Через консоль сервера (CLI):
     ```bash
     python send_eshop_deals.py --remove "Hogwarts Legacy"
     ```
2. **Що відбувається при видаленні**:
   - Бот знаходить повідомлення Hogwarts Legacy в топіку `561344` і безпечно видаляє його.
   - Видаляє гру з `data/eshop_active_showcase.json`.
   - Знімає 14-денний кулдаун з `data/eshop_posted_deals.json`.
   - Очищає кеш регіональних цін.
3. **Повторна генерація з реальними цінами**:
   - Інтерактивно в чаті або в особистих:
     ```text
     /search Hogwarts Legacy
     ```
   - Або запуск чергового циклу вітрини:
     ```bash
     python send_eshop_deals.py --force
     ```
