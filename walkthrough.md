# Звіт про виконану роботу: Команда перегляду активної вітрини (/showcase та CLI --list) (v0.7.30)

## Огляд задачі
Користувач надав посилання на топік eShop `https://t.me/kefir_ukr/561344` та попросив показати список усіх ігор, які туди додані.

---

## Реалізовано

1. **Інтерактивна команда в Telegram (`/showcase` або `/вітрина`)**:
   - `services/eshop/bot_commands.py`: додано команду `/showcase` (а також `/вітрина`, `/deals_list`, `/список`), яка миттєво повертає нумерований список усіх актуальних ігор, збережених у базі вітрини `data/eshop_active_showcase.json`, із цінами та відсотками знижки.
2. **CLI команда перегляду на сервері (`python send_eshop_deals.py --list`)**:
   - `send_eshop_deals.py`: додано команду `list_showcase_deals()` та флаг `--list` (або `list`, `--showcase`) для виведення списку ігор, їх ID повідомлень у топіку та цін прямо в термінал.
3. **Оновлення документації**:
   - Додано опис нових команд у `README.md` та меню `/help`.
4. **Тестування**:
   - Додано юніт-тести `test_cmd_list_showcase` та `test_cli_list_showcase`.
   - Усі 24 тести пройдено успішно (`pytest -v -n auto`).
