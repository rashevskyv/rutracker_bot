# Звіт про виконану роботу: Розклад та запуск Custom Releases Collector (v0.7.43)

## Огляд змін
Налаштовано розклад та способи запуску колектора кастомних репозиторіїв Nintendo Switch (`collect_custom_releases.py`) на 1 годину раніше за основний збір хоумбрю (о 07:00 за Київським часом / 04:00 UTC).

---

## 1. Автоматичний розклад у GitHub Actions
У файлі [.github/workflows/bot_runner.yml](file:///d:/git/dev/rutracker_bot/.github/workflows/bot_runner.yml):
- Додано крок автоматичного запуску `collect_custom_releases.py` о **04:00 UTC (07:00 Київ)**, що рівно на 1 годину випереджає основний збір хоумбрю `collect_homebrew_updates.py` (який стартує о **05:00 UTC / 08:00 Київ**).
- Додано опцію `run_collect_custom` до меню ручного примусового запуску (`workflow_dispatch`).

---

## 2. Способи виклику на власному Linux-сервері

### Варіант А: Через crontab сервера
Щоб скрипт автоматично спрацьовував щодня о **07:00 за Києвом** (на 1 годину раніше за основний хоумбрю-колектор о 08:00):
```bash
# Відкрити редактор crontab:
crontab -e

# Додати рядок:
0 7 * * * cd /шлях/до/rutracker_bot && ./run_custom_collector.sh >> /шлях/до/rutracker_bot/log/custom_collector.log 2>&1
```

### Варіант Б: Через універсальний раннер
```bash
./config/run_checker.sh custom
```
*(Універсальний раннер також автоматично підтягує актуальний стан з Gist перед стартом та вивантажує оновлений стан після)*.
