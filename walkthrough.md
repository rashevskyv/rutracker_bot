# Звіт про виконану роботу: Додано команду примусового перезапису та оновлення 20 повідомлень (`--reset`, `reset`) (v0.7.13)

## Огляд задачі
Користувач повідомив, що топік у Telegram наразі порожній (повідомлення були видалені вручну або очищені), однак у локальному файлі бази `data/eshop_active_showcase.json` зберігався стан 20 повідомлень, через що крон вважав вітрину заповненою (20/20). Користувач попросив команду, яка примусово скине локальну базу та опублікує 20 свіжих повідомлень з нуля для тестування додавання та видалення.

---

## Виконані кроки

1. **Додано прапорець `--reset` / `reset` / `--refresh`**:
   - `send_eshop_deals.py`:
     - Додано обробку прапорців `--reset`, `--refresh` або аргументів командного рядка `python send_eshop_deals.py reset` / `python send_eshop_deals.py --reset`.
     - При запуску з цим прапорцем бот автоматично:
       1. Очищає локальну базу стану вітрини `data/eshop_active_showcase.json`.
       2. Очищає історію нещодавно опублікованих ігор (кулдаун).
       3. Завантажує та публікує 20 свіжих топ-знижок із прямими клікабельними посиланнями для **ПАР 🇿🇦, Тайланду 🇹🇭, Польщі 🇵🇱, Норвегії 🇳🇴, США 🇺🇸**.
       4. Зберігає точні `message_id` нових 20 повідомлень для наступного безпомилкового видалення через `python send_eshop_deals.py remove all`.

2. **Тестування**:
   - Усі 18 тестів пройшли успішно (`pytest -v -n auto`).
