# Звіт про виконану роботу: Стабілізація регіональних цін та захист від рейт-лімітів (v0.6.99)

## Огляд проблеми
При пакетній обробці кількох ігор поспіль у перших повідомленнях (наприклад, *Celeste*) блок `🌍 Ціни в регіонах eShop:` відображався коректно, а в наступних (*Sonic Origins* тощо) зникав через те, що одночасний шквал із 17 запитів на гру викликав тимчасовий рейт-ліміт (403 Access Denied) від Akamai WAF на `api.ec.nintendo.com`.

---

## Виконані кроки

1. **12-годинний персистентний кеш цін (`data/eshop_region_prices_cache.json`)**:
   - `services/eshop/region_price_service.py`: Додано збереження отриманих регіональних цін у файл.
   - Повторні запуски крону та команди `/deals` беруть готові дані з кешу миттєво, не навантажуючи API та не викликаючи блокувань.

2. **Обмеження паралельних запитів (Semaphore + Pacing)**:
   - Встановлено `asyncio.Semaphore(4)` з мікро-паузами, завдяки чому запити надсилаються рівномірно і не перевантажують сервер Nintendo.

3. **Гарантований Algolia Fallback для цін США (USD)**:
   - Якщо офіційний Nintendo Price API не відповідає або тимчасово недоступний, бот автоматично звертається до Algolia Search API Nintendo of America, отримує точну ціну (`msrp`, `salePrice`, `lowestPrice`) та гарантовано відображає блок цін.

4. **Синхронізація з Gist**:
   - `sync_gist_state.py`: `eshop_region_prices_cache.json` додано до списку файлів синхронізації.

5. **Тестування**:
   - Усі 16 тестів пройшли успішно (`pytest -v -n auto`).
