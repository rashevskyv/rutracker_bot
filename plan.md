# План: Стиснення та санітизація ченджлогів і описів у Homebrew Digest

## Мета
Усунути потрапляння великих сирих мануалів/описів та багаторядкових нестиснених ченджлогів у дайджест хомбрю. Забезпечити компактність кожного запису (1–2 стислих речення без зайвої розмітки, сирого markdown-синтаксису та надлишкових абзаців).

## Етапи виконання

1. **Захисний санітайзер у форматтері дайджесту (`digest/homebrew.py`)**
   - [x] Реалізувати функцію `sanitize_digest_description(description: str) -> str`.
   - [x] Очищення від сирого Markdown (`**`, `###`, `*`, `[text](url)` тощо).
   - [x] Об'єднання переносів рядків в один рядок для основного опису та ченджлогу.
   - [x] Обмеження основного опису та ченджлогу до 1–2 перших речень.
   - [x] Застосування санітайзера у `format_digest_message`.

2. **Пріоритети коротких описів та валідація перекладу в колекторі (`collect_homebrew_updates.py`)**
   - [x] Пріоритет `description` перед `long_description`/`details` у джерелах UDB, ForTheUsers, VitaDB.
   - [x] У `_get_description_cached`: перевірка успішності перекладу (наявність кирилиці, відмінність від вхідного тексту), заборона кешування сирого англійського тексту, компактний фолбек `f"Додаток {fallback_name}."`.
   - [x] У `summarize_and_translate_notes`: попередня санітизація HTML/markdown та очищення виходу GPT до 1–2 речень чистого тексту.
