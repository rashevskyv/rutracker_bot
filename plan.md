# План розвитку: RuTracker Bot

## Загальний стан проєкту
RuTracker Bot забезпечує моніторинг релізів трекера, збір оновлень хоумбрю, перекладів українською (SWUK), ручних релізів та знижок Nintendo eShop з мультирегіональним порівнянням цін (топ-3 + Польща, США та інші), детекцією платформи Switch 1/2, графічними HD-бейджами платформ на обкладинках (без артефактів стиснення), фокусом на 100% популярних хітах (без сміття), інтерактивним списком бажань (Wishlist) з автосповіщеннями, гранулярними користувацькими підписками у приватних повідомленнях (`/subscriptions`), надійною відправкою (`allow_sending_without_reply`), живою вітриною до 20 ігор з авто-видаленням протермінованих знижок, посиланнями на eShop-Prices.com, потоковою відправкою у відповідь та в конкретні топіки/гілки, авторозсилкою в призначений топік `561344`, чітким маркуванням регіонів, хештегами жанрів, глобальним мульти-ключовим кешуванням перекладів та ШІ-обробкою через OpenRouter.

---

## Етапи та модулі

### Модуль 1: RuTracker Feed & Updates (OpenRouter / Luna / DeepSeek / Caching) [Виконано]
- Моніторинг Atom-стрічки, парсинг описів, переклад RU->UA через `openai/gpt-5.6-luna` з fallback на `deepseek/deepseek-v4-flash-0731`, SHA-256 кешування перекладів, валідація трейлерів YouTube. Підтримка доставки репостів роздач підписаним користувачам у приватні повідомлення.

### Модуль 2: Збір хоумбрю та локалізацій [Виконано]
- Підтримка Universal-DB, ForTheUsers, VitaForge, SwitchPorts, SWUK та користувацьких репозиторіїв із генерацією підсумків оновлень через OpenRouter та кешуванням у `hb_descriptions.json`.

### Модуль 3: Щоденні дайджести (Daily, Homebrew, Swuk) [Виконано]
- Агрегація та щоденна розсилка дайджестів у налаштовані канали/групи та особисто підписникам категорії `digests`.

### Модуль 4: Nintendo eShop Deals & Wishlist Module (v0.6.98) [Виконано]
- [x] Автоматичний моніторинг офіційних знижок Nintendo Switch без блокувань Cloudflare.
- [x] Алгоритм відбору знижок за каталогом 200+ найпопулярніших хітів та провідних видавців (100% якісні ігри, без shovelware).
- [x] **Кришталево чисті HD-обкладинки та векторний 2x supersampling редизайн бейджів платформ**:
  - Автоматичне завантаження `1600w` та `1200w` оригінальних HD-асетів з Nintendo CDN.
  - Редизайн у сучасний, компактний та елегантний стиль (заокруглений pill-шейп з м'якою тінню та акуратними Joy-Con іконками).
  - Збереження у максимальній якості `quality=96`, `subsampling=0` (4:4:4) без артефактів стиснення.
- [x] **Жива вітрина до 20 ігор (Live Showcase Rotation)**: бот підтримує актуальний пул з до 20 активних знижок у темі `561344`, автоматично видаляє повідомлення ігор, знижка на які закінчилася (`bot.delete_message()`), і дозаповнює звільнені слоти новими пропозиціями.
- [x] **Прямі посилання на `eShop-Prices.com`** у футері кожної картки (`🛒 Nintendo eShop | 🌐 eShop-Prices.com`).
- [x] **Персональний список бажань (Wishlist)**: команди `/wishlist`, `/wishlist add`, `/wishlist remove`, `/wishlist clear` з моніторингом цін у реальному часі.
- [x] **Гранулярні підписки в приватних повідомленнях (`/subscriptions`, `/sub`, `/unsub`)**:
  - За замовченням усі авто-пости у приватних **вимкнено** (бот відповідає лише на команди користувача).
  - Можливість увімкнути/вимкнути окремо: знижки (`deals`), репости з RuTracker (`rutracker`), дайджести (`digests`) або всі разом (`all`).
- [x] **Захист від помилок 400 при відповідях**: `allow_sending_without_reply=True` та автоматичний fallback у `safe_reply` і `safe_send_card`.
- [x] **Чисте форматування цін без знижок**: відображення чистої поточної ціни без закреслення та без `(-0%)`.
- [x] **Коректне закриття async клієнтів (`close_clients`)** при завершенні роботи крону.
- [x] **Автоматичні сповіщення про знижки на ігри з вішліста** в щогодинному/періодичному кроні.
- [x] Потокова послідовна відправка у `/deals` та `/search` у реальному часі безпосередньо **у відповідь на повідомлення користувача** та в **активний топік/гілку форуму**.
- [x] Автоматична розсилка по крону в призначений топік **`561344`**.
- [x] Чітке маркування базової ціни каталогу (`🇪🇺 Європа:`).
- [x] Глобальне мульти-ключове кешування описів ігор (SHA-256 + назва + fs_id) із логуванням `[CACHE HIT]` / `[CACHE MISS]`.
- [x] Дводіапазонний пошук цін: резолвінг як європейських, так і американських NSUID.
- [x] Мультирегіональне порівняння цін: топ-3 найдешевші регіони у світі (🥇, 🥈, 🥉) + гарантовані **Польща 🇵🇱 та США 🇺🇸**.
- [x] Автоматична конвертація в **гривні (грн / ₴)** для базової ціни та всіх регіональних цін.
- [x] Автоматичний переклад синопсисів/описів ігор на українську мову через OpenRouter з кешуванням у `translations_cache.json`.
- [x] Вивід жанрів оригінальними англійськими хештегами (`🏷 #Action #Adventure #RPG`).
- [x] Динамічні графічні бейджі платформ на обкладинках (Switch, Switch 2 Exclusive, Switch 1 & 2).
- [x] Інтервальний крон розсилки топ-знижок (`interval_hours`, `--force`).
- [x] Інтеграція оцінок Metacritic та RAWG для відсіювання сміття.
- [x] Інтерактивні команди в чатах через `bot_interactive.py`.
