# План: знижки Nintendo у США (v0.7.54)

## Мета

Показувати в eShop-вітрині ексклюзиви Nintendo, якщо знижка діє у США, навіть коли її немає в Європі.

## Реалізація й перевірка

1. [x] Додати основні ігри Nintendo до кураторського каталогу.
2. [x] Отримувати US NSUID через Algolia, а знижку підтверджувати живим Nintendo Price API для `US`.
3. [x] Зберігати USD/US у картці й повторно перевіряти її в тому самому регіоні.
4. [x] Додати регресійні тести та перевірити живі дані для Zelda і Mario.
5. [x] Запустити пов'язані тести: 54 пройдено у Windows Python.
