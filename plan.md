# План розвитку: RuTracker Bot

## Загальний стан проєкту
RuTracker Bot забезпечує моніторинг релізів трекера, збір оновлень хоумбрю, перекладів українською (SWUK), ручних релізів та знижок Nintendo eShop з мультирегіональним порівнянням цін (топ-3 + гарантовані **ПАР 🇿🇦, Тайланд 🇹🇭, Польща 🇵🇱, Норвегія 🇳🇴, США 🇺🇸**), клікабельними прямими посиланнями на регіональні eShop, стійким 12-годинним кешуванням та захистом від рейт-лімітів, детекцією платформи Switch 1/2, графічними HD-бейджами платформ на обкладинках (без артефактів стиснення), фокусом на 100% популярних хітах (без сміття), інтерактивним списком бажань (Wishlist) з автосповіщеннями, гранулярними користувацькими підписками у приватних повідомленнях (`/subscriptions`), рулеткою рандомних ігор (`/random [count] [rank] [price]`), гнучкими фільтрами та сортуванням знижок (`/deals [count] [rank] [price] [sort]`), примусовим скиданням та перепублікацією вітрини (`--reset`, `--refresh`, `reset`), підтримкою кириличних аліасів команд (`/допомога`, `/знижки`, `/пошук`, `/вішліст`, `/підписки`), автоматичним зняттям кулдауну при видаленні ігор, ізольованим очищенням вітрини через CLI (`--remove all`, `--remove 30`) та Telegram-команду (`/remove`) за точними збереженими ID повідомлень, централізованим рівнем безпеки `safe_delete_showcase_message` із суворим обмеженням видалення виключно топіком `561344` (`https://t.me/kefir_ukr/561344`), надійною відправкою (`allow_sending_without_reply`), живою вітриною до 30 ігор з авто-перевіркою та авто-видаленням протермінованих знижок, посиланнями на eShop-Prices.com, потоковою відправкою у відповідь та в конкретні топіки/гілки, авторозсилкою в призначений топік `561344`, чітким маркуванням регіонів, хештегами жанрів, глобальним мульти-ключовим кешуванням перекладів та ШІ-обробкою через OpenRouter.

## Етапи та модулі

### Модуль 1: RuTracker Feed & Updates (OpenRouter / Luna / DeepSeek / Caching) [Виконано]
- Моніторинг Atom-стрічки, парсинг описів, переклад RU->UA через `openai/gpt-5.6-luna` з fallback на `deepseek/deepseek-v4-flash-0731`, SHA-256 кешування перекладів, валідація трейлерів YouTube. Підтримка доставки репостів роздач підписаним користувачам у приватні повідомлення.

### Модуль 2: Збір хоумбрю та локалізацій [Виконано]
- Підтримка Universal-DB, ForTheUsers, VitaForge, SwitchPorts, SWUK та користувацьких репозиторіїв із генерацією підсумків оновлень через OpenRouter та кешуванням у `hb_descriptions.json`.

### Модуль 3: Щоденні дайджести (Daily, Homebrew, Swuk) [Виконано]
- Агрегація та щоденна розсилка дайджестів у налаштовані канали/групи та особисто підписникам категорії `digests`.

### Модуль 4: Nintendo eShop Deals & Wishlist Module (v0.7.17) [Виконано]
- [x] Автоматичний моніторинг офіційних знижок Nintendo Switch без блокувань Cloudflare.
- [x] **Рандомна гра зі знижкою (`/random`, `/рандом`, `/рулетка`)**:
  - Можливість отримати випадкову гру або пачку випадкових ігор з гнучким фільтром за рангом (наприклад `/random 4 1000-2000`) та ціною (наприклад `/random 4 1000-2000 100-500 грн`).
- [x] **Гнучкі параметри та сортування для `/deals`**:

    - `expensive` / `дорогі` — від найдорожчих.
    - `discount` / `%` — за розміром знижки.
    - `rating` / `рейтинг` — за оцінками Metacritic / RAWG.
    - `new` / `нові` — найновіші релізи.

- [x] **Гарантовані регіони (ПАР, Тайланд, Польща, Норвегія, США)**.
